# TrackBench

A generic job/task tracker recovered from JobTrak's useful ideas. The first core
validates dependencies, rejects cycles, identifies ready work, and calculates a
critical path.

```powershell
cargo test
cargo run
```

Next slices: durable jobs, assignments, due dates, filters, notes/attachments,
recurrence, time/cost entries, calendar views, and export/API adapters.
